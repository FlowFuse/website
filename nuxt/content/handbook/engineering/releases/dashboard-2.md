# Dashboard 2.0 Release Process

Releases of Node-RED Dashboard 2.0 are automated with [Release Please](https://github.com/googleapis/release-please), driven by Conventional Commits Pull Request titles. Merging the `chore: Release X.Y.Z` Pull Request it opens publishes the release to GitHub, npm and the Node-RED Flow Library.

The release process is documented, and maintained, in the [Release process](https://github.com/FlowFuse/node-red-dashboard/blob/main/README.md#release-process) section of the Dashboard repository's README.
