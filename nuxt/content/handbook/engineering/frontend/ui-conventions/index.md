# UI Conventions and Style Guide

The conventions we follow when building the FlowFuse platform UI. Each entry
covers one recurring decision, says what the agreed approach is, and shows the
code that implements it.

These pages describe how we want new work to look. Where you find older code
that does something different, prefer the convention documented here.

- [Feature Flags](./feature-flags.md) - how to define a flag and gate UI on it
