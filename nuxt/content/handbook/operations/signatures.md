# Signatures

FlowFuse uses HubSpot for generating quotes, and requesting the signatures on
them. For other legal documents we're using
[Google eSignatures](https://support.google.com/docs/answer/12315692?hl=en).

## Signature Circulation Requirements

Before requesting a signature on any document, the following must be in place and
communicated.

1. Context: state what the document is and what it supports.
2. Confirm all required signatures upfront — both internal and counterparty.
3. The document must be fully filled out before circulation. No placeholder text (e.g., [INSERT DESCRIPTION]) or incomplete fields should remain.
4. A Deal Desk task exists for the document, and its ID is included in the
   signature request. See [Legal](https://flowfuse.com/handbook/sales/legal#deal-desk-is-the-entry-point-for-all-legal-documents).
5. FlowFuse must be the last party to sign. Circulate to the counterparty (and any other external signatories) first, and only add the FlowFuse signature once every other party has signed.

For where to store the signed document, see [Legal](/handbook/sales/legal).
